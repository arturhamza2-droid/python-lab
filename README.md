# python-lab

Учебный Python-проект для изучения Python, Git, GitHub, VS Code и AI-разработки.

## Виртуальное окружение

В Windows PowerShell, находясь в папке проекта, создайте окружение:

```powershell
py -m venv .venv
```

Активируйте его:

```powershell
.\.venv\Scripts\Activate.ps1
```

## Запуск

После активации окружения выполните:

```powershell
python main.py
```
